Publicar no GitHub Pages

Siga os passos abaixo para hospedar o Aionix CI como um link público para seu time.

1
Clique no botão abaixo para baixar o arquivo index.html
2
Acesse github.com → New repository → nome: aionix-ci → Public → Create
3
Dentro do repo clique em Add file → Upload files e suba o index.html
4
Vá em Settings → Pages → Branch: main → Save
5
Em ~1 minuto o link fica disponível: seuusuario.github.io/aionix-ci
O arquivo contém todo o app — sem dependências externas além do CDN.
